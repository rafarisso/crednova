# CredNova

Landing page desenvolvida para uma empresa do segmento de recuperação de crédito.

O projeto foi criado com foco em apresentação institucional, geração de confiança e captação de interessados em serviços relacionados à regularização financeira e negociação de dívidas.

## Sobre o projeto

A CredNova é uma landing page voltada para comunicação comercial de uma recuperadora de crédito.

A proposta da página é apresentar os serviços de forma clara, objetiva e profissional, ajudando potenciais clientes a entenderem como a empresa pode auxiliar em processos de negociação, reorganização financeira e recuperação de crédito.

Este projeto foi desenvolvido como uma solução web leve, responsiva e preparada para publicação em ambiente de produção.

## Objetivo

O objetivo principal da landing page é transformar visitantes em contatos qualificados.

Para isso, a página foi pensada para comunicar:

- quem é a empresa
- quais problemas ela resolve
- quais serviços oferece
- como o cliente pode entrar em contato
- por que confiar na solução apresentada

## Público-alvo

A landing page foi pensada para pessoas e empresas que buscam apoio em situações como:

- dívidas em aberto
- restrição de crédito
- necessidade de renegociação
- organização financeira
- recuperação de acesso ao crédito
- orientação para regularização de pendências

## Principais características

- Layout moderno e responsivo
- Estrutura clara de apresentação dos serviços
- Comunicação direta e comercial
- Foco em conversão
- Página leve e objetiva
- Deploy preparado para Netlify
- Organização de código para evolução futura
